# F1 25 Setup

1. Launch F1 25.
2. Open **Settings → Telemetry Settings**.
3. Configure:
   - **UDP IP Address:** `127.0.0.1`
   - **UDP Port:** `20777` (default)
   - **UDP Format:** `2025`
   - **UDP Send Rate:** `20 Hz` (recommended)
4. Start driving **complete timed laps** — the game only sends useful telemetry during timed laps. Returning to the garage or making a pit stop after a timed lap starts a new stint.
5. Keep SimTelemetry running to listen on UDP port 20777.

If another telemetry tool is already bound to port 20777, close it or change the port in both the game and SimTelemetry settings.
