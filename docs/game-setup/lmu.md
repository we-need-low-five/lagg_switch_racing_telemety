# Le Mans Ultimate Setup

1. Ensure Le Mans Ultimate 1.2 or newer.
2. Official shared memory interface should be active (`LMU_Data` mapping).
3. Enter a session and drive on track.
4. If telemetry is not detected, verify the game's `Support/SharedMemoryInterface` documentation for your build.

Optional legacy plugin users may also use the rFactor2 shared memory plugin, but SimTelemetry targets the official LMU interface first.
