# Assetto Corsa Competizione Setup

1. Install and launch ACC.
2. Enter Practice, Hotlap, or Race session on any track.
3. Shared memory is enabled by default — no plugin required.
4. Keep SimTelemetry running in the system tray.
5. Drive complete timed laps; invalid/out laps are filtered automatically.

SimTelemetry detects `acc.exe` and reads `Local\acpmf_physics`, `Local\acpmf_graphics`, and `Local\acpmf_static`.
